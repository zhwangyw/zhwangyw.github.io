# 深度学习速查卡（鱼书核心浓缩版）

> 用途：忘记概念时快速翻阅。配合 [学习路线-PyTorch](/knowledge/learning-roadmap-pytorch) 使用
> 原则：**先动手写代码，忘了再来翻这张卡** —— 不要背，要用

## 一、神经网络基础
- **感知机**：多输入 → 加权求和 → 阈值判断（阶跃）。神经网络 = 感知机的平滑版（激活函数替代阶跃）
- **神经元输出**：\(y = f(Wx + b)\)，\(W\) 权重、\(b\) 偏置、\(f\) 激活函数
- **激活函数**：
  - sigmoid：\(1/(1+e^{-x})\)，输出 0~1，用于二分类输出层
  - ReLU：\(max(0,x)\)，隐藏层默认首选（解决梯度消失）
  - softmax：多分类输出层，输出和为 1（概率分布）

## 二、损失函数
- **均方误差 MSE**：回归任务。\(\frac{1}{2}(y-t)^2\)
- **交叉熵**：分类任务。\(-t\log y\) —— 分类默认用这个
- 损失函数的意义：衡量"预测离真实多远"，训练就是最小化它

## 三、训练核心：梯度下降 + 反向传播
- **梯度**：损失对每个参数的偏导，指示"参数往哪调能降低损失"
- **梯度下降**：\(W \leftarrow W - \eta \frac{\partial L}{\partial W}\)，\(\eta\) 学习率
- **反向传播**：从输出层向输入层逐层计算梯度（链式法则）。PyTorch 里就是 `loss.backward()` 自动完成
- **学习率**：太小收敛慢，太大震荡不收敛（常用 0.001~0.1 量级）
- **epoch/batch**：epoch=整个数据集过一遍；batch=每次更新用多少样本（mini-batch 是标准做法）

## 四、防止过拟合的武器
- **L2 正则（权重衰减 weight decay）**：损失加 \(\lambda||W||^2\)，让权重别太大
- **Dropout**：训练时随机丢弃部分神经元（PyTorch: `nn.Dropout(p)`）
- **BatchNorm**：每层输入归一化，加速收敛 + 轻微正则（PyTorch: `nn.BatchNorm2d`）
- **数据增强**：翻转/裁剪/加噪，增加训练样本多样性
- **早停**：验证集不再提升就停

## 五、权重初始化
- **Xavier 初始化**：sigmoid/tanh 系，均匀分布 \(U(-\sqrt{6/(n_{in}+n_{out})}, ...)\)
- **He 初始化**：ReLU 系，\(\sqrt{2/n_{in}}\) —— **ReLU 就用 He**
- 初始化差 → 梯度消失/爆炸，网络学不动

## 六、优化器（PyTorch 都有现成的）
| 优化器 | 特点 | 什么时候用 |
|--------|------|-----------|
| SGD | 朴素，可加 momentum | 基线/理论验证 |
| Momentum | 带惯性，越过局部极小 | 比 SGD 快 |
| AdaGrad | 自适应学习率 | 稀疏数据 |
| Adam | 自适应 + 动量，**默认首选** | 绝大多数任务开箱即用 |

## 七、CNN（你的课题核心）
- **卷积层**：`nn.Conv2d(in_ch, out_ch, kernel_size)` —— 提取局部特征
  - 参数：kernel（如 3×3）、stride（步长）、padding（填充保持尺寸）
  - **输出尺寸**：\((H - k + 2p)/s + 1\)
- **池化层**：`nn.MaxPool2d(kernel_size)` —— 下采样降维，保留主要特征
- **感受野**：输出像素能看到输入多大区域，层越深感受野越大
- **通道数**：浅层学边缘/纹理，深层学语义（脸/物体）
- **经典结构**：Conv → BN → ReLU → Pool，堆叠 + 最后全连接/全局池化

## 八、经典网络（面试可能问）
- **VGG**：小卷积核（3×3）堆深
- **GoogLeNet (Inception)**：多尺度卷积并行 + 1×1 卷积降维
- **ResNet**：残差连接 \(F(x)+x\)，解决深层退化 —— **现在绝大多数模型的骨架**
- 记住一句话：**ResNet 的残差思想 = 让梯度有"高速公路"直达浅层**

## 九、Transformer 一句话（d2l 会细讲）
- 自注意力：每个 token 与所有 token 算相关性加权求和，**并行化 + 长程依赖**
- 位置编码：给 token 加位置信息（Transformer 本身无序）
- 2026 年 CV 里 ViT 已主流，但你课题（偏振成像）CNN 足够起步
