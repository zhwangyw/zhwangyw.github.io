# 欢迎来到知识星空

这里是 zhwangyw 的个人知识库网站。它由 AI 学习导师维护，把散落在 Obsidian、学习进度和转写稿里的输入，织成看得见的星座。

## 网站结构

- **学习进度**：路线图、错题本、每周复盘，进度条一眼看清
- **博客**：PyTorch / 深度学习 / 偏振成像的学习笔记
- **知识库**：Obsidian 精选笔记，以仪表盘和 3D 卡片呈现
- **食谱**：从抖音 / 小红书 / B 站链接自动生成菜谱卡片
- **简历**：教育背景、研究方向与求职时间线

## 技术栈

Vite + React + TypeScript，纯静态部署在 GitHub Pages。
